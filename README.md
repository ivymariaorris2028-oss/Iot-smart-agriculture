# IoT-Based Smart Agriculture System

An interactive single-page web dashboard and showcase for precision farming powered by sensing, wireless communication, and cloud automation.

* Christeena K Peter
* Delna Theresa Domanic

## Features
- **Interactive Hardware Simulator**: Test ESP32 threshold logic and pump control loop in real time.
- **Live Telemetry & Chart**: Real-time rendering of soil moisture trends using Chart.js.
- **System Architecture & Stack**: Visual breakdown of Perception, Network, and Application layers.
- **Traditional vs. Smart IoT Comparison**: Comprehensive feature comparison table.
- **Future Roadmap**: Details on AI/ML integration, LoRaWAN, solar nodes, and drone monitoring.

## GitHub Pages Deployment
1. Upload all files (`index.html`, `README.md`) to your GitHub repository.
2. Go to **Settings** > **Pages**.
3. Under **Source**, select `main` branch and `/ (root)`.
4. Click **Save**. Your site will be live!
